Tabel Analisis Platform: Web, Desktop, Mobile
Aspek	Web	Desktop	Mobile
Bahasa utama	HTML, CSS, JavaScript (plus framework: React, Vue, Angular; backend: Node.js, PHP, Python)	C#, C++, Java, Swift (macOS), Electron (JavaScript/HTML/CSS untuk cross-platform)	Kotlin/Java (Android), Swift/Objective-C (iOS), Dart (Flutter), JavaScript (React Native)
Arsitektur	Client-server, berjalan di browser; kode di server, UI dirender di browser	Aplikasi native yang berjalan langsung di atas OS; bisa standalone atau client-server	Aplikasi native yang di-install di perangkat; sering terhubung ke backend via API
Cara distribusi	Tanpa instalasi — cukup akses via browser dan URL; update otomatis di server	Perlu installer (.exe, .dmg, .deb); distribusi via download, USB, atau enterprise deployment	Via app store (Google Play, App Store) atau sideloading APK; update melalui store
Keunggulan	Portabilitas sangat tinggi (bisa diakses dari perangkat apa pun yang punya browser dan internet); tidak perlu instalasi; update terpusat; remote connection bawaan	Performa tinggi karena memanfaatkan resource penuh komputer; bisa offline; stabil untuk aplikasi berat	Mobilitas tinggi (selalu dibawa); akses hardware native (GPS, kamera, sensor); portabilitas tinggi antar perangkat mobile
Keterbatasan	Bergantung pada koneksi internet; akses hardware terbatas; UI mungkin kurang optimal di layar sentuh kecil	Distribusi dan instalasi sulit; portabilitas rendah (terikat OS); tidak dirancang untuk remote connection	Layar relatif kecil; tool development lebih terbatas; distribusi via app store memiliki aturan ketat; pengembangan lebih kompleks
Contoh aplikasi	Google Docs, Figma, Tokopedia (web), YouTube (web), Canva	Microsoft Word, Adobe Photoshop, Visual Studio Code, game PC (Steam)	WhatsApp, Instagram, Gojek, Mobile Legends, Spotify (mobile)
